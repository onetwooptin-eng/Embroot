# Reference function parity audit

The uploaded archive was inspected as a WordPress/WooCommerce mirror. The public EmberRoot build remains original static HTML/CSS/JavaScript.

## Implemented in EmberRoot v2

- Five-language navigation and hreflang structure
- Product catalogue, category pages, search, category filter, sorting, price range, pagination and grid/list views
- Product detail pages with packaging options, quantity controls, image zoom, share, wishlist, tabs, visible FAQ and related/recent products
- Persistent quote cart, mini-cart drawer, quantity editing and request subtotal
- Quote checkout with email, WhatsApp, copy, text download, print and local save
- Browser-local account, wishlist, saved request history and quote-reference tracker
- Responsive mobile menu, global product search, quick view, cookie notice, reading progress and back-to-top
- Contact and wholesale enquiry forms using email/WhatsApp hand-off
- Product, article, organization, website and FAQ structured data
- PWA manifest and service-worker app-shell cache

## Requires a backend or external service before it can be real

- Customer authentication, password recovery and server-side accounts
- Live stock quantities, warehouse allocation and price administration
- Card/crypto/bank payments, refunds and fraud controls
- Real tax, customs and freight calculations
- Order creation, fulfilment statuses and courier tracking
- Transactional emails, invoice generation and administrative dashboard
- Server-side contact-form delivery, spam protection and consent logging
- Verified customer reviews

These features cannot be securely reproduced with static browser code alone. Integration hooks and clear placeholders are included instead of fake processing.
